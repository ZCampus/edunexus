# EduNexus

Multi-tenant school management for African schools (SmartShule). Attendance, marks, fees, and role-based portals that still work on weak networks.

## Apps

- `web/` — Next.js 15 student, parent, teacher, and headmaster portals (mock-first MVP)

## Student portal (MVP)

Dashboard, profile, timetable, homework, period-level attendance, exams, results, announcements, learning materials, messages, calendar, and settings.

## Run locally

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000/login](http://localhost:3000/login).
